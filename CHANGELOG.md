- Adicionada UI para iniciar e responder ao diagnóstico, preservando feedback antes de avançar.
- Adicionados testes API Python, scripts Windows/macOS/Linux, documentação de arquitetura, pedagogia e implantação, e execução dos testes Python no GitHub Actions.
